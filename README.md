# GitIngest (Personal Use Only)

> **Notice:** This repository and codebase are strictly for personal use and nothing else. It is not intended, supported, or maintained for public or commercial usage.

---

## Overview

A customized personal tool designed to ingest, inspect, and analyze GitHub repositories into consolidated, LLM-ready text digests with directory tree visualizations, token metrics, and custom filtering.

## Personal Workflow Features

- **Personal Access Token (PAT) Integration:** Configured to ingest personal and private repositories seamlessly.
- **Owner Security Gate:** Passcode verification to protect private personal sessions.
- **Custom Preferences:** Persists personal exclude/include filters and size boundaries across sessions.
- **Digest Export:** Generates clean directory trees and file contents formatted for LLM context windows.

This repository is maintained solely for personal use. No external support or public distribution is provided.
